# Security policy

This project is a set of instructions and a local Python script; it handles no credentials and runs no
network service. The script downloads icon packs from Google's official URLs over HTTPS and reads/writes
local `.drawio` files.

If you find a security issue (for example, a crafted `.drawio` file causing unexpected behavior in the
script), please report it privately through
[GitHub security advisories](https://github.com/EBMBA/gcp-architecture-diagram-skill/security/advisories/new)
rather than a public issue.
